An entry for [The Self-Checkout Is Judging You](https://make.fun/competitions/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) on [make.fun](https://make.fun).

This program writes a single funny line in the voice of a smug, judgmental self-checkout machine. The till speaks in the first person about one very specific shopper — twelve yoghurts, nothing else — and treats the purchase as a formal incident: it logs the basket, keeps the receipt as evidence, and escalates it to the store nutritionist, whose reaction is the sting. The joke lands cold on a single read, with no setup and no borrowed self-checkout clichés.

Run it with `node main.ts` (Node 22); it deterministically writes the line to `/output/entry.txt`.
